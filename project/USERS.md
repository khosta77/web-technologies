# Информация для отладки пользователей

## Получение информации о пользователе по ID профиля

Если вы видите URL профиля пользователя, например: `http://127.0.0.1:8000/profile/171/`

Вы можете получить информацию о пользователе (логин и пароль) с помощью команды:

```bash
poetry run python manage.py get_user_info 171
```

Команда выведет:
- **ID пользователя**
- **Username (логин)**
- **Email**
- **URL профиля**
- **Пароль** (если используется стандартный тестовый пароль)
- **Рейтинг пользователя**
- **Количество вопросов и ответов**

## Стандартные тестовые пароли

Все пользователи, созданные через команду `fill_db`, имеют стандартный пароль: **`12345`**

## Пример использования

```bash
# Получить информацию о пользователе с ID 171
poetry run python manage.py get_user_info 171

# Вывод:
# ============================================================
# ИНФОРМАЦИЯ О ПОЛЬЗОВАТЕЛЕ
# ============================================================
# ID: 171
# Username: пользователь123
# Email: user123@example.com
# URL профиля: http://127.0.0.1:8000/profile/171/
# 
# ============================================================
# ДАННЫЕ ДЛЯ ВХОДА
# ============================================================
# Логин: пользователь123
# Пароль: 12345
# 
# ✓ Пароль подтвержден
```

## Сброс пароля

Если стандартный пароль не подходит, вы можете сбросить пароль пользователя:

```bash
poetry run python manage.py changepassword <username>
```

## Получение списка всех пользователей

Чтобы получить список всех пользователей в базе данных:

```bash
poetry run python manage.py shell -c "from django.contrib.auth.models import User; [print(f'{u.id}: {u.username}') for u in User.objects.all()]"
```

## Создание суперпользователя для доступа к админ-панели

Для доступа к Django админ-панели (`http://127.0.0.1:8000/admin/`) необходимо создать суперпользователя:

```bash
poetry run python manage.py createsuperuser
```
