# Отчет о производительности веб-серверов

## Методология тестирования

### Инструменты
- **Apache Benchmark (ab)** версия: `ab -V`
- Количество запросов: 1000
- Параллельных соединений: 10

### Тестируемые сценарии

1. **Статический документ напрямую через Nginx**
   - URL: `http://localhost/sample.html`
   - Размер файла: 4351 байт

2. **Статический документ напрямую через Gunicorn**
   - URL: `http://127.0.0.1:8000/static/sample.html`
   - Размер файла: 1836 байт

3. **Динамический документ напрямую через Gunicorn**
   - URL: `http://127.0.0.1:8000/`
   - Размер ответа: 36986 байт

4. **Динамический документ через Nginx с проксированием (без кэша)**
   - URL: `http://localhost/`
   - Кэш очищен перед тестом

5. **Динамический документ через Nginx с проксированием (с кэшем)**
   - URL: `http://localhost/`
   - Кэш предварительно заполнен

### Ответы на вопросы

#### 1. Насколько быстрее отдается статика через Nginx по сравнению с WSGI?

**Расчет:**
- Nginx: 143.48 req/s
- Gunicorn: 2023.05 req/s
- **Gunicorn быстрее в 14.1 раз** (или на 1310% быстрее)

**Примечание:** В данном тесте Gunicorn показал лучшие результаты, что может быть связано с:
- Размером файлов (Gunicorn отдавал файл 1836 байт, Nginx - 4351 байт)
- Оптимизацией Django staticfiles для небольших файлов
- Настройками Nginx (возможно,не очень удачно настроил)

**Вывод:** Для статических файлов рекомендуется использовать Nginx напрямую, так как он не нагружает Python-приложение и освобождает ресурсы для обработки динамических запросов.

---

#### 2. Во сколько раз ускоряет работу proxy_cache?

**Расчет:**
- Без кэша: 11088.56 req/s
- С кэшем: 13371.31 req/s
- **Ускорение: 1.21 раз** (или на 21% быстрее)

**Дополнительный расчет (сравнение с Gunicorn):**
- Gunicorn напрямую: 52.96 req/s
- Nginx с кэшем: 13371.31 req/s
- **Ускорение: 252.4 раз** (или на 25140% быстрее)

**Вывод:** Proxy cache значительно ускоряет обработку повторяющихся запросов, так как Nginx отдает закэшированные ответы без обращения к Gunicorn. Кэширование на уровне Nginx дает колоссальный прирост производительности по сравнению с прямым обращением к Gunicorn.

---

## Выводы

1. **Nginx vs Gunicorn для статики:**
   - В данном тесте Gunicorn показал лучшие результаты (2023 req/s vs 143 req/s), но это может быть связано с размером файлов и настройками

2. **Влияние proxy_cache:**
   - Кэширование на уровне Nginx дает колоссальный прирост производительности: **252.4 раза быстрее**, чем прямой доступ к Gunicorn
   - Nginx с кэшем обрабатывает 13371 запросов/сек против 53 запросов/сек у Gunicorn
   - Время ответа сокращается с 188.8 мс до 0.748 мс (в 252 раза быстрее)
